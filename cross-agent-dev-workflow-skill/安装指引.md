# 🚦 cross-agent-dev-workflow · 安装指引

> 这份指引是给**收到本技能包的 Agent / Harness** 看的。按下面步骤自助安装即可。

---

## 这个 skill 是什么

跨 Agent / 跨 Harness 的**项目全生命周期交付总流程技能**（研发迭代 → 测试纠错 → 整理发布三阶段，证据制验收门 + 停止闸 + 阶段状态机），与 `cross-agent-memory`（就地记忆）、`cross-agent-scratchpad-skill`（临时脚本治理）**三位一体**深度联动——建议三件套整装。

---

## 一、安装位置（选你所在的 harness）

`SKILL.md` 是**标准技能格式**，只需把整个 `cross-agent-dev-workflow-skill` 文件夹放进该 harness 认的 skills 目录。

| Harness | 安装目录 | 命令（PowerShell） |
|---|---|---|
| ZCode | `C:\Users\<你>\.zcode\skills\cross-agent-dev-workflow-skill` | `robocopy <本目录> "$HOME\.zcode\skills\cross-agent-dev-workflow-skill" /E` |
| Codex CLI | `C:\Users\<你>\.codex\skills\dev-workflow`（或 `.agents\skills\`） | `robocopy <本目录> "$HOME\.codex\skills\dev-workflow" /E` |
| Cursor | `C:\Users\<你>\.cursor\skills\cross-agent-dev-workflow-skill` | `robocopy <本目录> "$HOME\.cursor\skills\cross-agent-dev-workflow-skill" /E` |
| Claude Code | `C:\Users\<你>\.claude\skills\cross-agent-dev-workflow-skill` | `robocopy <本目录> "$HOME\.claude\skills\cross-agent-dev-workflow-skill" /E` |

> 可安装到多个 harness（同一份，互不影响）。

## 二、验证是否装好

装好后，本会话/环境应能**加载名为 `cross-agent-dev-workflow-skill` 的 skill**。可检查：
- 对应 skills 目录下 `cross-agent-dev-workflow-skill\SKILL.md` 存在。
- 会话的技能目录里出现 `cross-agent-dev-workflow-skill`。
-（可选）跑 `python 工具\发布管家.py 校验技能 <本目录>` 做规范自检。

## 三、第一次使用（在某个工作区）

只要在这个环境里执行任务，就按 SKILL.md 协议使用：
1. **接手**：与 memory/scratchpad 共用一键入口（`记忆管家.py 接手 <工作区>` 或手工等价），读取记忆 `5_代办` 的「🚦 交付流程状态」段定续跑点。
2. **定档**：轻量 / 标准 / 深度。触发面宽（制作/开发/改进/测试/发布类任务皆会触发本技能），但进入后先定档——小改动走轻量路径；用户说「ultrathink / 深度研究迭代到可上线发布」等即深度档。
3. **走阶段**：只走触达的阶段，每阶段过证据制验收门；验收门一过即停（停止闸）。

## 四、可选工具（推荐 Python 3.8+）

- 主工具：`工具\发布管家.py`——`校验技能` / `三位一体` / `打包` / `发布检查`。
- Windows 薄封装：`工具\发布管家.ps1`（转发到 Python）。
- 没有 Python 时按 SKILL.md 协议手工操作，完全成立。

## 五、可移植 / 多电脑

- 技能本体是纯 Markdown 文件夹，拷到新电脑的 skills 目录即可。
- 阶段状态存放在各项目的记忆里（随项目文件夹走），换电脑换 Agent 都能续跑。
