# 🧠 cross-agent-memory — 跨 Agent / 跨 Harness 就地记忆技能

> 让任何 Agent / Harness 在**真实工作区的文件夹树里就地沉淀并继承记忆**。
> 记忆不是集中放在某个"记忆库"，而是**直接嵌在工作区自己的文件夹里，随工作区走**。

> 📘 **技能说明见 `SKILL.md`**（任何支持 skill 的 Agent 都能加载本技能）。

---

## 核心思想

1. **就地嵌入**：记忆文件夹直接建在真实工作区/项目的文件夹树里，命名带层级（`记忆第一层`/`记忆第二层`/`记忆第三层`/`记忆第四层`……），每个含完整 6 件。**层号 = 记忆层级序数**（根=第一层；分组文件夹不建层就不占层号）。
2. **层数由 Agent 深度研究后自主决定（1~N 层，不设上限）**：接手时 Agent **独立深度研究分析项目的真实结构**，判断该分几层、每层对应哪个文件夹、每层职责——不是固定三层。简单项目一层即可，复杂多级工程四层五层也行；结论写成「**分层方案**」记入根记忆层 `0_索引`，后续 Agent 遵循。
3. **Agent 深度理解后填写**：首次使用工作区时，Agent 深度阅读全部项目文件 + 融合对话经验记忆，**自己归纳总结项目知识填写 6 件**（不是拷空模板）。
4. **每次对话/任务后实时更新，写前三步（先读→合并→写回）**：装了这个 skill 后，**每次执行任务或每次对话结束都更新记忆**——更新前**必须先深度阅读该层现有记忆**（可用 `记忆索引.json` 指纹校验检测其他 Agent 的并发写入），**在原有基础上修改、合并、优化，绝不覆盖/清空**；更新以**追加带日期+署名的条目**为主，定期整理防膨胀。
5. **接手任务先读记忆（强制）**：只要装了本 skill，接手任何工作任务时**第一步必须先读根层 `0_索引`（分层方案），再深度阅读项目里的记忆文件**；没有记忆文件就**深度阅读整个项目文件**后自主定层。
6. **层级完整性检查（主动补齐）**：每次使用都递归扫描工作区，**主动为新增的模块/子工程（任意深度）按分层方案补齐对应层号的记忆层，不等用户提醒**（如 platforms/{windows,macos,android,ios,harmonyos}）。
7. **每次任务都用**：执行任何任务都使用它——无记忆文件夹则研究后定层、添加，有则每次对话/任务后更新。

## 就地嵌入示例（工作区 `D:\AAA实习\新闻爬虫`，Agent 研究后决定分 4 层）

```
D:\AAA实习\新闻爬虫\                    ← 第一层（工作区/所有任务）
│   └── 记忆第一层\（6件）
│
├── 爬取新闻\                           ← 第二层（相近任务）
│   ├── 记忆第二层\（6件）
│   └── AI_NEWS_MARKETS\
│       ├── CHINA\                      ← 第三层（单项目模块）
│       │   └── 记忆第三层\（6件）
│       ├── WORLD\                      ← 第三层（单项目模块）
│       │   └── 记忆第三层\（6件）
│       └── LEGACY\                     ← 第三层（老系统值得单独记，所以 LEGACY 也建层）
│           ├── 记忆第三层\（6件）
│           └── 老系统\                 ← 第四层（因为 LEGACY 已占第三层）
│               └── 记忆第四层\（6件）
```

**每层 7 件**：`0_索引`（速览+更新日志；根层还记「分层方案」，接手先读）+ `1_项目架构` / `2_踩坑日志` / `3_个性化需求` / `4_提示词配方` / `5_代办` / `6_需要我配合.txt`，另有 `记忆索引.json` 指纹档案（工具维护，用于并发检测）。

## 使用流程

1. **接手任务时（强制第一步）**：可用一键入口 `python 工具\记忆管家.py 接手 <工作区>`（扫描记忆层 + 层级完整性检查 + 并发校验 + 联动配置检查），或手工：先读根层 `0_索引`（分层方案），再深度阅读项目里的记忆文件；没有记忆文件则**深度阅读整个项目文件**。
2. **层级完整性检查**：递归扫描工作区，主动为新增的模块/子工程（任意深度）补齐对应层号的记忆层（结构变化/拆分子工程后必做；层数变深先修订「分层方案」）。
3. **开始任务前**：定位所在工作区，查看是否已有 `记忆第X层` 文件夹。
   - 没有 → 深度阅读工作区 + 融合对话经验，**独立研究判断分几层（1~N 层不设上限）**，就地创建并填写 `0_索引` + 6 件 + 分层方案。
   - 有 → **先深读现有记忆**（尤其 `5_代办`、`6_需要我配合`），理解上下文；可用 `校验` 检测外部改动。
4. **执行中 / 每次对话后**：踩坑立刻向 `2_踩坑日志` 追加条目；需求确认记入 `决策.md`(可选)/`5_代办`；用户配合事项更新 `6_需要我配合`。
5. **完成后**：**先深读现有记忆，再在原基础上更新**（写前三步：先读→合并→写回）`0_索引`、`5_代办`、`1_项目架构`（结构变化）等，并刷新指纹档案。

## 目录

```

├── README.md                       ← 本文件

└── 工具/
    ├── 记忆管家.py                  ← 主工具（Python 3.8+）：接手/建层/扫描/检查/索引/校验（支持一~九十九层）
    └── 记忆助手.ps1                 ← Windows 薄封装（转发到 Python）
```

## 跨 harness / 跨电脑

- **跨 harness**：`SKILL.md` 是标准技能格式，任何支持 skill 的 Agent 都能加载；复制 `cross-agent-memory-skill/` 到对应 harness 的 skills 目录即可。
- **跨电脑**：因为记忆就嵌在工作区文件夹里，**把工作区文件夹拷过去，记忆跟着走**；skill 本体（`cross-agent-memory-skill/`）拷到新机器的 skills 目录即可用。
- 判断层数、判断层级、深度理解填写由 Agent 自主完成，无需脚本；工具只按「层号=记忆层级序数」做机械推断与校验。
