# 🧠 cross-agent-memory · 安装指引

> 这份指引是给**收到本技能包的 Agent / Harness** 看的。按下面步骤自助安装即可。

---

## 这个 skill 是什么

跨 Agent / 跨 Harness 的**就地记忆技能**：在任何真实工作区/项目文件夹树里，就地创建并维护记忆文件夹（`记忆第X层`，层号 = 记忆层级序数，**层数由 Agent 深度研究项目后自主决定，1~N 层不设上限**），每层含 `0_索引` + 6 件记忆文件，让任何 Agent 接手相同/相似/相关任务时都能「完整理解并接管」。**用户说"这是通用的"时，Agent 写到中央 `记忆_通用/`（与 记忆第一层 平级）并刷新所有层 0_索引 的「🔗 通用知识」段引用——任何项目、任何层都能调用。** **记忆内路径用 `<工作区>/xxx` 占位，禁写机器专属绝对路径，换电脑复制文件夹后照常生效。**

---

## 一、安装位置（选你所在的 harness）

`SKILL.md` 是**标准技能格式**，只需把整个 `cross-agent-memory-skill` 文件夹放进该 harness 认的 skills 目录。

| Harness | 安装目录 | 命令（PowerShell） |
|---|---|---|
| ZCode | `C:\Users\<你>\.zcode\skills\cross-agent-memory-skill` | `robocopy <本目录> "$HOME\.zcode\skills\cross-agent-memory-skill" /E` |
| Codex CLI | `C:\Users\<你>\.codex\skills\memory`（或 `.agents\skills\`） | `robocopy <本目录> "$HOME\.codex\skills\memory" /E` |
| Cursor | `C:\Users\<你>\.cursor\skills\cross-agent-memory-skill` | `robocopy <本目录> "$HOME\.cursor\skills\cross-agent-memory-skill" /E` |
| Claude Code | `C:\Users\<你>\.claude\skills\cross-agent-memory-skill` | `robocopy <本目录> "$HOME\.claude\skills\cross-agent-memory-skill" /E` |

> 可安装到多个 harness（同一份，互不影响）。

## 二、验证是否装好

装好后，本会话/环境应能**加载名为 `cross-agent-memory` 的 skill**。可检查：
- 对应 skills 目录下 `cross-agent-memory-skill\SKILL.md`（或 `memory\SKILL.md`）存在。
- 会话的技能目录里出现 `cross-agent-memory`。

## 三、第一次使用（在某个工作区）

只要在这个环境里执行任务，就**自动使用本 skill**：
1. 接手任务时**先读 `0_索引`，再深度阅读项目里的记忆文件**（没有则深度阅读整个项目）。
2. 每次对话/任务后**实时更新记忆**（写前三步：先读→合并→写回，绝不覆盖）。
3. 每次使用做**层级完整性检查**：主动为新增的模块/子工程（任意深度）按「分层方案」补齐对应层号的记忆层。

## 四、可选工具（推荐 Python 3.8+）

- 主工具：`工具\记忆管家.py`（跨平台）——`接手`（一键接手入口）/`建层`/`扫描`/`检查`/`索引`/`校验`（并发指纹检测）。
- Windows 薄封装：`工具\记忆助手.ps1`（转发到 Python；文件为 UTF-8 with BOM）。
- 没有 Python 时按 SKILL.md 协议手工操作，完全成立。

## 五、可移植 / 多电脑

- 记忆就嵌在工作区文件夹里，**把工作区文件夹拷过去，记忆跟着走**。
- skill 本体（`memory`）拷到新电脑的 skills 目录即可。
