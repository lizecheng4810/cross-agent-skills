# cross-agent-memory 安装指引

把整个 `cross-agent-memory-skill` 文件夹安装到 Harness 能发现的 skills 目录。安装路径按目标 Harness 配置决定，示例：

| Harness | 常见目录 |
|---|---|
| Codex | `~/.agents/skills/cross-agent-memory` 或 `~/.codex/skills/cross-agent-memory` |
| Claude Code | `~/.claude/skills/cross-agent-memory` |
| Cursor | `~/.cursor/skills/cross-agent-memory` |
| 其他支持 Agent Skills 的 Harness | 该 Harness 的 skills 目录 |

各 Harness 的目录和加载规则可能随版本变化；以当前安装版本的官方文档为准。确认安装后，确保整个文件夹（含 `references/`、`工具/` 和模板）都已复制。

## 首次在工作区使用

1. 若工作区已经有记忆，按 `SKILL.md` 的快速路径读根索引与当前交接，再定位目标范围。
2. 若没有记忆，才研究项目结构、确定 1~N 层的分层方案，并在根索引写清层职责与不建层例外。
3. 新层默认建精简索引和交接文件；稳定主题有内容时再创建对应文件。完整审计仅在初始化、结构变化、记忆冲突或明确要求时运行。
4. 使用可选工具时先看 [工具说明](工具/README.md)。默认接手只检查相关路径；`--full-audit` 才扫描全工作区。

没有 Python 时可以按技能文件与模板手工操作；不需要为了使用记忆协议额外安装软件。
