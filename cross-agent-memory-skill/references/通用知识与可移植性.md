# 通用知识、路径和例外目录

## 中央通用记忆

仅当用户明确指出内容适用于跨项目的“通用知识”时，写入工作区根目录下的 `记忆_通用/`。其中保存 `0_通用索引.md` 和有真实内容的通用主题，不在项目记忆中复制全文。各层 `0_索引.md` 用 `## 🔗 通用知识` 列出必要链接。

项目/模块专属结论留在相应项目层。无法确认是否通用时，先留在当前项目范围。

## 例外目录

将“记忆层是否覆盖”与“记忆内容如何描述”分开判断。源码模块通常需要时可分层；生成物、第三方依赖、缓存、数据集、构建目录及可移植的技能/模板发布包一般不需要自己嵌入项目记忆。最终取舍以工作区根索引的明确分层方案为准。不要将技能包目录自动改造成记忆层，也不要为每个目录候选机械补齐层结构。

## 跨 Agent / Harness 可移植

- 路径使用项目内相对路径，跨工作区时使用 `<工作区>` 占位符。
- 确认目标 Agent 实际能读的文件入口；不能默认它支持特定工具或命令。
- 先通过索引与文件名提供渐进读取路径；没有 Python 时使用宿主的搜索/文件读取能力。
- 留下足以恢复工作的目标、边界、已完成动作、下一步、状态依据，而非长篇对话转录。
- 个人配置、绝对安装路径和机器状态不是跨设备保证；重新接手时按宿主能力核验。
