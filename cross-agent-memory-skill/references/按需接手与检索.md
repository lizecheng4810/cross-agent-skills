# 按需接手与检索

## 常规接手顺序

1. 读工作区根记忆层的 `0_索引.md`，确认分层方案、例外目录和全局约束。
2. 读根层 `5_代办.md` 中当前有效的交接/交付状态；没有活跃任务时跳过过期状态。
3. 根据用户目标、明确路径、当前工作区差异或分支信息，定位最深的相关记忆层。
4. 读该层 `0_索引.md` 和 `5_代办.md`；仅打开索引指向且与任务有关的主题文件。
5. 将记忆作为线索。涉及当前代码、配置、运行状态或版本时，回到真实项目源核对。

默认不读兄弟模块的记忆，不逐层打开所有六类文件。只有当前目标跨模块、上层规则对当前任务有约束，或检索结果提示关联时，才继续向外扩展。

## 何时扩大读取

- 找不到任务相关记忆，或当前索引缺失/明显过期；
- 记忆与当前代码、配置、用户本轮指令冲突；
- 当前任务跨多个模块，无法从单一路径确定范围；
- 用户要求完整接管、全面审计或追溯历史；
- 指纹校验显示目标层在上次记录后有变化。

扩大时先读相关层，再读其直接父层；只有仍有缺口时才读更广范围。首次接手无任何记忆时，才进行一次项目结构研究和定层。

## 交接记录

`5_代办.md` 保持为短恢复点，至少包含目标、范围、最后完成动作、可立即执行的下一步、阻塞和依据。长期架构、偏好、决策和踩坑分别写入对应的主题文件，`5_代办.md` 只放链接。

对复杂交付可选用 `交接简报.md`。不把整段历史会话、完整日志或本可从代码直接读取的细节复制进交接文件。

## 工具用法

默认快速接手，只检查任务目标路径上的层：

以下命令从 `cross-agent-memory-skill` 技能目录运行。

```powershell
python 工具\记忆管家.py 接手 <工作区> --scope <工作区内的目标目录或文件>
```

没有确定目标路径时省略 `--scope`，快速入口只检查根层。确需完整审计时显式运行：

```powershell
python 工具\记忆管家.py 接手 <工作区> --full-audit
python 工具\记忆管家.py 检查 <工作区>
```

记忆位置不清楚或索引不足时，先按范围检索，再打开少量命中来源：

```powershell
python 工具\记忆管家.py 检索 <工作区> "登录状态" --term "token" --scope <工作区内的目录> --top 10
```

检索当前为本地词面匹配，不提供语义召回。把用户用语、代码符号、模块名和可能的同义词作为独立关键词；没有结果时扩大范围或直接核对项目文件。检索命中不代表记忆仍然有效。

没有 Python 时，按相同范围策略用 `rg`、文件搜索或 Harness 提供的文件工具；不要因为没有搜索程序就全量读入所有层。
