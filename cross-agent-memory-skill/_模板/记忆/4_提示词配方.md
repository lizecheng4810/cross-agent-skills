# 4_提示词配方

> **填写说明**：沉淀两类：① 写得特别好的需求模板（可复用）；② 写得差的需求诊断 + 重写模板（回给用户改进）。**主要来源是对话**——用户说"这个需求清楚/写得不好"时，记录下当时确认的模板和写法。

## 一、好的提示词模板（"写得特别好"时记录）
### 模板：`[模板名]`
```text
【目标】我想要……（一句话结果）
【背景】为什么需要 / 现状
【输入】我能提供什么 / 材料在哪
【验收】怎样算完成（可量化）
【约束】不要做什么 / 边界 / 技术栈
【示例】期望的输入输出
【待你确认】需要拍板的点
```
> 适用于：[什么场景]

## 二、差需求诊断 + 重写模板（"写得不好"时给用户）
**常见失败原因**：目标不清 / 缺验收 / 缺背景 / 没给约束 / 缺输入材料 / 一条塞太多目标。

**给用户的重写模板**：
```text
【目标】【背景】【输入】【验收】【不要】【示例】
```
> 引导用户填完上面 6 项，Agent 再开工。
