# _模板 —— 记忆文件夹的格式参考（不是填空模板）

> ⚠️ **最重要：这些不是"填空模板"，而是"格式参考"。**
> 使用时，Agent 必须先**深度阅读并理解工作区/该层的全部项目文件**，**并深度结合对话经验/上下文记忆**（本次对话里用户说的偏好、澄清、确认过的决策、踩过的坑、纠正过的地方），再**自己归纳总结**，把真实项目知识 + 对话经验写进 6 件。不能拷过去留空，也不能只依赖项目文件。

## 记忆文件夹命名（就地嵌入，层号 = 记忆层级序数）

**层数不是固定的**：Agent 深度研究项目结构后自主决定分几层（1~N 层，不设上限），层号 = 记忆层级序数（根=第一层；某文件夹的层号 = 路径上拥有记忆层的祖先数 + 1，分组文件夹不建层就不占层号）：

| 举例的层 | 文件夹名 | 放哪 |
|---|---|---|
| 第一层 | `记忆第一层` | 工作区根目录下 |
| 第二层 | `记忆第二层` | 根下一级（如任务类/平台矩阵文件夹）下 |
| 第三层 | `记忆第三层` | 再下一级（如单项目/模块）下 |
| 第四层… | `记忆第四层`… | 更深的子模块（值得单独记就建，不设上限） |

> 每层文件夹里都放**完整 6 件**。某级没有独立知识就不建层；分几层、每层职责写进根记忆层 `0_索引` 的「分层方案」。

## 6 件格式参考（每层都要有）

| # | 文件 | 写什么（Agent 深度理解后归纳） |
|---|---|---|
| 1 | `1_项目架构.md` | 该层结构、有哪些模块/文件、怎么配合、数据怎么流 |
| 2 | `2_踩坑日志.md` | 实际踩过的坑：问题/原因/解决/影响 |
| 3 | `3_个性化需求.md` | 命名/注释/字段习惯（下层覆盖上层标 ⚠️） |
| 4 | `4_提示词配方.md` | 好需求模板；差需求的诊断+重写模板 |
| 5 | `5_代办.md` | 当前进度、下一步、预估的坑 |
| 6 | `6_需要我配合.txt` | 需用户补充/拍板/材料，按重要性 |

> 可选扩展：`决策.md`（已确认的需求/澄清）、`交接简报.md`（接手主入口）、`工具环境.md`（可用工具/技能/约束）。

## 怎么用

1. **接手任务时（强制第一步）**：先深度阅读项目里的记忆文件（`记忆第X层/` 6 件）；没有记忆文件则**深度阅读整个项目文件**。
2. 首次使用工作区（无记忆）：深度阅读工作区全部文件 + 融合对话经验 → **独立研究分析判断分几层（1~N 层不设上限）** → 就地建各 `记忆第X层` 文件夹（层号=记忆层级序数） → 深度理解后填 6 件，并把「分层方案」写进根层 `0_索引`。
3. 已有记忆文件夹：Agent **先深度阅读现有 6 件**（可能已被其他 Agent/Harness 写入）→ 执行任务 → **每次对话/任务后在原基础上更新 6 件（读后改，不覆盖）**。
4. 参考 `_模板/记忆/` 下的格式，但内容必须来自对项目的真实理解 + 对话经验。
