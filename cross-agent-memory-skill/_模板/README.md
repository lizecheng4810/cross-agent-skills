# 记忆模板说明

`_模板/记忆/` 是按需创建文件时的格式参考，不是要求每层填满的目录清单。内容必须基于当前证据和用户已确认的信息；不要留空文件来追求形式完整。

## 默认布局

```text
记忆第一层/
├── 0_索引.md       路由索引与根层分层方案
├── 5_代办.md       当前恢复点和下一步
└── 记忆索引.json   工具维护的指纹档案
```

子层默认相同。旧式完整布局继续可读；需要按旧模板创建时使用 `记忆管家.py 建层 ... --完整模板`。

## 主题文件何时创建

| 文件 | 仅在有以下持久内容时创建 |
|---|---|
| `1_项目架构.md` | 稳定的模块边界、数据流、运行或验证入口 |
| `2_踩坑日志.md` | 已遇到且未来可能重现的问题与解决方法 |
| `3_个性化需求.md` | 用户明确表达或有充分证据支持的稳定偏好 |
| `4_提示词配方.md` | 使用验证过、可复用的提示词或诊断模板 |
| `6_需要我配合.txt` | 正在等待用户提供材料、答复或拍板 |
| `决策.md` / `工具环境.md` | 需要跨任务追溯的决策或环境事实 |

## 使用时

1. 常规接手先读根层 `0_索引.md` 和当前 `5_代办.md`，再按任务路径读取范围层索引、交接与相关主题。
2. 首次没有记忆时，按工作区结构研究分层；不用逐个读入无关的构建产物、缓存或第三方依赖。
3. 读取主题文件遵循索引路由；任务无关的主题和兄弟层不必打开。
4. 只记录有长期复用价值的内容。写入前重读目标文件并合并；无新信息时不写。
5. 全工作区完整性审计仅在首次初始化、结构变化、记忆冲突或用户要求时执行；先判断目录候选是否真的需要独立记忆层。

索引结构见 [`记忆/0_索引.md`](记忆/0_索引.md)，当前交接结构见 [`记忆/5_代办.md`](记忆/5_代办.md)。
