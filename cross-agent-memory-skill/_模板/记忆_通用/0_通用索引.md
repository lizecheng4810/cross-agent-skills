# 0_通用索引（跨层通用知识索引）

> **本文件夹是什么**：用户在对话中明确标注「这是通用的」知识，全部沉淀在这里。**任何** `记忆第N层` 都能通过本层 `0_索引.md` 的「🔗 通用知识」段查到并引用——不需要在每个层各复制一份。
>
> **写入触发**：用户说"这是通用的"/"跨项目都这样"/"不管哪个项目都按这个"/类似表述 → Agent 把内容写到这里，并刷新所有层的 0_索引引用。
>
> **路径约定（可移植）**：本文档所有路径用 `<工作区>/xxx` 或相对路径表达，**绝不写死**机器专属绝对路径（因为换电脑时整个 AI 文件夹会被复制走，绝对路径会失效）。

## 本索引用法
- 接手 Agent 先读本页 → 知道有哪些通用知识 → 必要时打开对应明细件查完整内容
- 每件都按主题归类，不要散落
- 用户说"这个改成通用的"或"取消通用"时，立刻在这里更新并刷新所有 `记忆第N层/0_索引.md` 的引用
