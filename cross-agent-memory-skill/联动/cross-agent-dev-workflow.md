# cross-agent-memory × cross-agent-dev-workflow

`cross-agent-dev-workflow` 负责交付阶段与验收；`cross-agent-memory` 为续跑提供状态和稳定上下文。阶段流程写入记忆，不要求读取与任务无关的所有层或主题。

## 阶段状态存放

| 内容 | 位置 | 维护方式 |
|---|---|---|
| 当前档位、阶段、进度、证据、下一步 | 任务对应层 `5_代办.md` 的 `🚦` 段 | 阶段转移或阻塞变化时更新；保持为恢复点 |
| 验收清单 | 项目验收文件；或 `5_代办.md` 的短摘要与直链 | 开始时建立，阶段验收时更新 |
| 已拍板方案和取舍 | 相关层的 `决策.md`（有内容时） | 保留待续跑有用的决定与依据 |
| 可复用问题与修复 | `2_踩坑日志.md`（按需创建） | 仅记录有复用价值的内容 |
| 稳定用户偏好 | `3_个性化需求.md`（按需创建） | 仅记录用户明确表达或有充分证据的内容 |
| 结构性发布变化 | `1_项目架构.md`（按需创建） | 架构/模块关系变化时修订 |
| 待用户决定/材料 | `6_需要我配合.txt`（有事项时） | 相关任务接手时读取；已解决项关闭 |

## 接手与续跑

```text
任务开始
 ├─ memory 快速路径：根 0_索引 + 当前 5_代办
 ├─ 按任务路径：范围层 0_索引 + 5_代办 + 相关主题
 ├─ scratchpad：核对本机配置；只在无可信审计标记时做首次脚本遗留物审计
 └─ 读取该任务相关的 🚦 状态 → 从记录的阶段/下一步续跑
```

工具快捷方式：

```powershell
python "<cross-agent-memory技能目录>\工具\记忆管家.py" 接手 <工作区> --scope <任务路径>
```

未给范围时只检查根层。仅在首次初始化、结构变化、记忆冲突或明确要求时运行 `接手 <工作区> --full-audit`。无记忆时按任务范围确认当前文件；只有首次定层或结构不明时才深度研究整个项目。

记忆更新始终遵循“读目标文件 → 合并 → 写回 → 回读确认”。无长期价值的轮次不制造空更新；阶段状态有变化时则及时更新相关 `5_代办.md`。路径用相对路径或 `<工作区>` 占位符。
