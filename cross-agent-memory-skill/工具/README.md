# 记忆管家（可选工具）

Python 3.8+ 的跨平台辅助程序，负责建层、路径定位、完整性候选检查、词面检索和指纹校验。它不决定哪些知识值得记，也不自动创建候选层。

保留 3.8 兼容是为了兼容旧环境；Python 3.8 已结束上游支持，建议使用仍受支持的 Python 版本。[Python 3.8.20 发布说明](https://www.python.org/downloads/release/python-3820/)

从技能目录运行以下命令；无 Python 时可以手工遵循 `SKILL.md`。

## 接手与审计

```powershell
# 默认快速模式：只检查工作区根层；不会遍历全工作区
python 工具\记忆管家.py 接手 "<工作区>"

# 检查任务路径上的记忆层，不扫描兄弟目录
python 工具\记忆管家.py 接手 "<工作区>" --scope "<工作区内路径>"

# 明确要求全面盘点时使用；会扫描全部记忆层并检查指纹
python 工具\记忆管家.py 接手 "<工作区>" --full-audit

# 单独做完整性候选检查；默认不限目录深度，自动跳过符号链接和已声明例外
python 工具\记忆管家.py 检查 "<工作区>"
python 工具\记忆管家.py 检查 "<工作区>" --scope "<子目录>" --max-depth 4
```

根层 `0_索引.md` 的 `## 例外目录` 段可用反引号列出相对路径，完整性检查与全层扫描会跳过这些路径。其他候选只提示人工依据分层方案判断；“目录有 README/项目标志文件”不等于必须建层。

## 建层

```powershell
# 默认只生成 0_索引.md、5_代办.md 和指纹档案
python 工具\记忆管家.py 建层 "<目录>" --层 1

# 兼容旧式完整模板，同时创建六类主题文件
python 工具\记忆管家.py 建层 "<目录>" --层 1 --完整模板

# 创建中央跨层通用知识文件夹（只在用户明确要求时）
python 工具\记忆管家.py 建层 "<工作区>" --通用
```

层号必须服从根索引中确认的分层方案；工具不会根据目录深度替 Agent 决定认知层级。索引/主题文件应按需填写，不要为齐全而保留空文件。

## 检索与并发指纹

```powershell
# 大小写不敏感词面匹配；可添加词并限定子目录
python 工具\记忆管家.py 检索 "<工作区>" "登录状态" --term "token" --scope "src/auth" --top 10

# 每个记忆层保存/检查指纹
python 工具\记忆管家.py 索引 "<工作区>" --层 记忆第一层 --by "agent名"
python 工具\记忆管家.py 校验 "<工作区>" --层 记忆第一层

# 完成合并写入后再刷新；同时清理已删除标准主题的旧指纹
python 工具\记忆管家.py 索引 "<工作区>" --层 记忆第一层 --by "agent名"

# 更新某层通用知识引用
python 工具\记忆管家.py 刷新通用 "<工作区>" --by "agent名"
```

词面命中仅用于定位，不提供语义召回；校验是并发检测，不是文件锁。发现被改动的目标文件时先重读并合并，再刷新指纹。完整参数见：

```powershell
python 工具\记忆管家.py --help
python 工具\记忆管家.py 接手 --help
```
