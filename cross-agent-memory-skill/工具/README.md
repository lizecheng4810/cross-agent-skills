# 记忆管家 / 记忆助手（cross-agent-memory 辅助脚本 · 可选）

> ⚠️ **脚本是可选的辅助**。判断第1/2/3层、深度阅读并填写记忆，由 **Agent 按 SKILL.md 自主完成**。脚本只负责「就地建记忆文件夹」「扫描」「层级完整性检查」「指纹校验」这类机械操作。

- **主工具**：`记忆管家.py`（Python 3.8+，跨平台）
- **薄封装**：`记忆助手.ps1`（Windows，转发到 Python）

## 命令

### 0. 一键接手入口（推荐：两技能共用的接手第一步）
```powershell
python 工具\记忆管家.py 接手 "D:\AAA实习\新闻爬虫"
```
效果：一条命令跑完「扫描已有记忆层 → 层级完整性检查（缺 记忆第三层 的候选）→ 各层并发校验 → 本机临时脚本库配置联动检查（联动 cross-agent-scratchpad）」，并给出后续动作提示。

### 1. 就地建记忆文件夹
```powershell
python 工具\记忆管家.py 建层 "D:\AAA实习\新闻爬虫" --层 一
python 工具\记忆管家.py 建层 "D:\AAA实习\新闻爬虫\爬取新闻" --层 二
python 工具\记忆管家.py 建层 "D:\AAA实习\新闻爬虫\爬取新闻\AI_NEWS_MARKETS\CHINA" --层 三
# PowerShell 薄封装等价写法：
.\工具\记忆助手.ps1 建层 "D:\AAA实习\新闻爬虫" --层 一
```
效果：在目标文件夹里就地创建 `记忆第X层`，含 `0_索引` + 6 件格式参考 + 初始 `记忆索引.json`。
> ⚠️ 建完后，Agent 要深度理解该层内容，归纳总结后填写（不是留空）。

### 2. 扫描已有的记忆文件夹
```powershell
python 工具\记忆管家.py 扫描 "D:\AAA实习\新闻爬虫"
```

### 3. 层级完整性检查（找出缺记忆第三层的子模块文件夹）
```powershell
python 工具\记忆管家.py 检查 "D:\AAA实习\王梓旭"
```
效果：检查「一级子目录 + platforms 下各平台」，报告哪些缺 `记忆第三层`。
> ⚠️ 发现缺失时，Agent 应立即补齐并填写，**不等用户提醒**（尤其拆分工程/平台后）。

### 4. 指纹档案（并发检测）
```powershell
# 每次更新完记忆后，记录当前指纹：
python 工具\记忆管家.py 索引 "D:\AAA实习\新闻爬虫" --层 记忆第一层 --by zcode
# 下次更新前，检测是否被其他 Agent/Harness 改过：
python 工具\记忆管家.py 校验 "D:\AAA实习\新闻爬虫" --层 记忆第一层
# 合并完成后刷新指纹：
python 工具\记忆管家.py 校验 "D:\AAA实习\新闻爬虫" --层 记忆第一层 --refresh
```
效果：`校验` 列出自上次记录后被修改/新增/删除的记忆文件 → **更新前必须先深读被改文件、合并后再写回**；`索引` 在各层文件夹里维护 `记忆索引.json`（sha256 + mtime + 更新者）。**这是检测不是互斥锁**，最终靠协议纪律。`--by` 省略时自动取本机 `~/.agent-tsg/config.json` 的 `agent_name`（与 cross-agent-scratchpad 共享）；指纹档案写入为原子写入，并发下不会留半截 JSON。

## 说明
- `记忆第X层` 文件夹名由 Agent 判断层级后指定：一=记忆第一层，二=记忆第二层，三=记忆第三层。
- 判断哪些文件夹是第1/2/3层、以及省略某层，属于 Agent 的自主判断（见 `SKILL.md`），脚本不代劳。
- **结构变化（新增子工程/模块/平台文件夹）后，务必跑一次 `检查`，为缺失的 `记忆第三层` 补齐。**
