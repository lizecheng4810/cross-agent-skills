# 记忆管家 / 记忆助手（cross-agent-memory 辅助脚本 · 可选）

> ⚠️ **脚本是可选的辅助**。判断分几层（1~N 层不设上限）、深度阅读并填写记忆，由 **Agent 按 SKILL.md 自主完成**。脚本只按「**层号 = 记忆层级序数**（根=第一层；某文件夹的层号 = 路径上拥有记忆层的祖先数 + 1，分组文件夹不建层不占层号）」做机械操作：「就地建记忆文件夹」「扫描」「层级完整性检查」「指纹校验」。

- **主工具**：`记忆管家.py`（Python 3.8+，跨平台）
- **薄封装**：`记忆助手.ps1`（Windows，转发到 Python）

## 命令

### 0. 一键接手入口（推荐：三技能共用的接手第一步）
```powershell
python 工具\记忆管家.py 接手 "D:\AAA实习\新闻爬虫"
```
效果：一条命令跑完「记忆_通用 检查（[0] 段）→ 扫描已有记忆层 → 层级完整性检查（缺对应层号记忆层的候选）→ 各层并发校验 → 本机临时脚本库配置联动检查（联动 cross-agent-scratchpad）」，并给出后续动作提示（cross-agent-dev-workflow 的阶段0 也走这个入口）。

### 1. 就地建记忆文件夹（普通层 或 中央通用层）
```powershell
python 工具\记忆管家.py 建层 "D:\AAA实习\新闻爬虫" --层 1
python 工具\记忆管家.py 建层 "D:\AAA实习\新闻爬虫\爬取新闻" --层 二
python 工具\记忆管家.py 建层 "D:\AAA实习\新闻爬虫\爬取新闻\AI_NEWS_MARKETS\CHINA" --层 3
python 工具\记忆管家.py 建层 "D:\AAA实习\新闻爬虫\爬取新闻\AI_NEWS_MARKETS\CHINA\子模块" --层 四   # 层数不设上限（一~九十九）
python 工具\记忆管家.py 建层 "D:\AAA实习\新闻爬虫" --通用                                              # 建中央 记忆_通用\（0_通用索引+4件）
# PowerShell 薄封装等价写法：
.\工具\记忆助手.ps1 建层 "D:\AAA实习\新闻爬虫" --层 1
```
效果：在目标文件夹里就地创建 `记忆第X层`，含 `0_索引` + 6 件格式参考 + 初始 `记忆索引.json`；`--通用` 则创建 `记忆_通用\`（5 件 + 指纹档案），`索引/校验` 命令也认 `--层 记忆_通用`。
> ⚠️ 建完后，Agent 要深度理解该层内容，归纳总结后填写（不是留空）。

### 2. 扫描已有的记忆文件夹
```powershell
python 工具\记忆管家.py 扫描 "D:\AAA实习\新闻爬虫"
```

### 3. 层级完整性检查（找出缺记忆层的子模块文件夹，任意深度）
```powershell
python 工具\记忆管家.py 检查 "D:\AAA实习\王梓旭"
```
效果：递归扫描（向下最多 3 级），按记忆层级序数推断每处应有的 `记忆第X层`，报告哪些候选缺层。候选判定 = 一级子目录、或有项目标志文件（README/package.json/.git 等）的目录、或 platforms 下各平台。
> ⚠️ 发现缺失时，Agent 应立即补齐并填写，**不等用户提醒**（尤其拆分工程/平台后）；缺的层超出「分层方案」现有层数时，先修订根层 `0_索引` 的分层方案再建层。

### 4. 指纹档案（并发检测）
```powershell
# 每次更新完记忆后，记录当前指纹：
python 工具\记忆管家.py 索引 "D:\AAA实习\新闻爬虫" --层 记忆第一层 --by zcode
# 下次更新前，检测是否被其他 Agent/Harness 改过：
python 工具\记忆管家.py 校验 "D:\AAA实习\新闻爬虫" --层 记忆第一层
# 合并完成后刷新指纹：
python 工具\记忆管家.py 校验 "D:\AAA实习\新闻爬虫" --层 记忆第一层 --refresh
```
效果：`校验` 列出自上次记录后被修改/新增/删除的记忆文件 → **更新前必须先深读被改文件、合并后再写回**；`索引` 在各层文件夹里维护 `记忆索引.json`（sha256 + mtime + 更新者）。**这是检测不是互斥锁**，最终靠协议纪律。`--by` 省略时自动取本机 `~/.agent-tsg/config.json` 的 `agent_name`（与 cross-agent-scratchpad 共享）；指纹档案写入为原子写入，并发下不会留半截 JSON。

### 5. 刷新所有层的「🔗 通用知识」段
```powershell
python 工具\记忆管家.py 刷新通用 "D:\AAA实习\新闻爬虫" --by zcode
```
效果：按当前 `记忆_通用/` 重建**每一个** `记忆第X层/0_索引.md` 的「🔗 通用知识」段——已填的摘要保留、新增的通用文件补上（摘要留 `[摘要]` 由 Agent 填）、失效引用删除；受影响层的指纹档案同步刷新。用户说「这是通用的」并写入中央后，跑这一条完成 §八·三 的第 3 步。

### 6. 跨层全文检索
```powershell
python 工具\记忆管家.py 检索 "D:\AAA实习\新闻爬虫" "编码检测"
```
效果：在全部 `记忆第X层/` 与 `记忆_通用/` 的 .md/.txt 里检索关键词，输出 `文件:行号:内容`（每文件最多 5 行）。层多记不住内容在哪时，先检索再精读，别全量通读。

## 说明
- `记忆第X层` 文件夹名按「**层号 = 记忆层级序数**」指定：根=一（记忆第一层）；某文件夹的层号 = 根到它的路径上拥有记忆层的祖先数 + 1——分组文件夹（AI_NEWS_MARKETS、platforms 等）自己不建层就不占层号（记忆第二层、第三层……九十九）。层号接受中文或阿拉伯数字。
- 判断分几层（1~N 层不设上限）、哪些文件夹该建层、以及省略某级，属于 Agent 的自主判断（见 `SKILL.md`），脚本只按深度做机械推断。
- **结构变化（新增子工程/模块/平台文件夹）后，务必跑一次 `检查`，为缺失的记忆层补齐。**
