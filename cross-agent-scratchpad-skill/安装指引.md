# 安装指引

## 前置条件

- Python 3.8+（推荐；没有时 PS 封装仅支持初始化配置，Agent 可按 SKILL.md 手工执行协议）
- 建议三件套整装：`cross-agent-memory` + 本技能 + `cross-agent-dev-workflow-skill`（三位一体联动设计，单独使用会失去记忆延续与交付流程调度能力）

## 安装位置（选你所在的 harness）

`SKILL.md` 是标准技能格式，把整个 `cross-agent-scratchpad-skill/` 文件夹放进对应 skills 目录即可：

| Harness | 安装目录 |
|---|---|
| ZCode | `C:\Users\<你>\.zcode\skills\cross-agent-scratchpad-skill\` |
| Codex CLI | `C:\Users\<你>\.agents\skills\cross-agent-scratchpad-skill\` |
| Cursor | `C:\Users\<你>\.cursor\skills\cross-agent-scratchpad-skill\` |
| Claude Code | `C:\Users\<你>\.claude\skills\cross-agent-scratchpad-skill\` |

> 多个目录各放一份（或做目录联接 `mklink /J`），即可跨 Agent/Harness 共用同一份 skill。

## 首次使用（每台设备一次）

任何 Agent 首次在本设备执行任务时，会按协议询问你：**本设备的临时脚本统一存放位置在哪里？**

也可以提前手动配置（省去询问）：

```powershell
python "<skill目录>\工具\临时脚本管家.py" 配置 --path "D:\你的临时脚本库"
```

配置写入 `~\.agent-tsg\config.json`，仅本机生效；跨设备时各设备各自配置。

## 验证安装

```powershell
python "<skill目录>\工具\临时脚本管家.py" 报告
```

能输出库内摘要即安装成功。
