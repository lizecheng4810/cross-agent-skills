# 与 cross-agent-memory 的联动约定

memory 负责工作区记忆和续跑路由，scratchpad 负责外部临时脚本库和遗留物治理。接手共用一个入口，但按任务范围读取记忆。

## 接手任务入口

```text
接手任务
 ├─ 1. 按 memory 快速路径读根 0_索引 + 当前 5_代办
 ├─ 2. 按任务路径读范围层索引/交接与相关主题
 ├─ 3. 读本机 ~/.agent-tsg/config.json，确认临时脚本库可用
 ├─ 4. 若已有可信审计标记，只做增量检查；否则做首次脚本遗留物审计
 └─ 5. 任务结束按元数据处置本轮脚本，并仅沉淀长期可复用的经验
```

命令：

```powershell
python "<cross-agent-memory技能目录>\工具\记忆管家.py" 接手 <工作区> --scope <任务路径>
```

默认快速接手不做全工作区记忆层审计。确需完整记忆审计时显式使用 `--full-audit`。这不改变 scratchpad 在无审计标记时进行首次临时脚本遗留物审计的要求。

## 信息归属

| 信息 | 归属位置 |
|---|---|
| 设备级临时脚本库路径 | 本机配置 `~/.agent-tsg/config.json` |
| 可复用脚本的元数据与哈希 | 外部库 `manifests/index.json` |
| 脚本库审计报告 | 外部库 `reports/` |
| 用户明确的长期治理偏好 | 有内容时的 memory `3_个性化需求.md` |
| 某工作区稳定的审计范围/结论 | 相关 memory 层 `5_代办.md` 或 `1_项目架构.md` |
| 经验证的路径/依赖故障 | 有内容时的 memory `2_踩坑日志.md` |
| 待用户确认的隔离文件 | memory `6_需要我配合.txt`（有事项时） |

memory 文件仅在值得跨任务复用时更新。共享文件写入先重读并合并；指纹仅用于发现并发变更，不是互斥锁。机器绝对路径只保存在本机配置中，不复制进可移植记忆。
